# ممیزی واقعی وب‌سایت حاکم ذهن

تاریخ: ۲۶ اکتبر ۲۰۲۶. محدوده: مخزن عمومی `hosiinabaszadeh84/hakem-zehn-website` و نشانی `https://hosiinabaszadeh84.github.io/hakem-zehn-website/`؛ بررسی محدود کد محلی اپلیکیشن برای صحت ادعاها. مخزن خصوصی یا دادهٔ کاربران منتشر نشده است.

## شواهد اولیه

- صفحهٔ اصلی عمومی: HTTP 200، بدون ورود، Canonical صحیح در مسیر پروژه، بدون هدر X-Robots-Tag مسدودکننده در پاسخ ثبت‌شده. فایل شواهد: `scratch/seo-qa/home-headers.txt` و `home-before.html`.
- `/robots.txt` واقعی ریشهٔ میزبان: HTTP 404. این پاسخ به معنای مسدودشدن خزش نیست. `robots.txt` داخل `/hakem-zehn-website/` جای فایل ریشه را نمی‌گیرد. کنترل robots ریشه با این مخزن پروژه ممکن نیست؛ ساخت مخزن دیگری یا مهاجرت برای این موضوع ضروری نیست.
- Sitemap اولیه فقط خانه، حریم خصوصی و دریافت را داشت. صفحات آموزشی مستقل وجود نداشتند.
- مالکیت Search Console در ابتدای اجرا تأیید نشده بود؛ پنجرهٔ روش HTML file باز بود. فایل واقعی مالک دریافت و جداگانه منتشر شد. سپس پیام `Ownership auto verified` مشاهده شد؛ تصویر `delivery/website/seo/02-google-verified.png`.
- Overview پس از تأیید برای Performance، Indexing و Experience پیام «Processing data, please check again in a day or so» نشان داد. نبود گزارش آماده معادل صفر نمایش یا صفر صفحهٔ ایندکس‌شده نیست.

## مسیر تجربه و شواهد تصویری

1. **پیش‌نمایش برنامه:** تصویر `01-before-experience.png`؛ هویت تیره و پیش‌نمایش واقعی منسجم است، اما منوی قبلی راهنمای مستقلی نداشت. اصلاح: ناوبری راهنماها و امکانات مستقل.
2. **ورود از راهنماها:** تصویر `03-guides-mobile.png`؛ عنوان روشن، تاریخ واقعی بازبینی، فهرست محتوا و مسیر برگشت. چیدمان در موبایل خواناست. صحت علمی با منابع بررسی شده؛ تصویر به‌تنهایی اثربخشی بالینی را ثابت نمی‌کند.
3. **انتخاب ابزار / دریافت:** تست مرورگر نشان داد انتخاب نیاز، گالری، تنفس و حالت‌های مدل کار می‌کنند. لینک فروشگاه عمداً غیرفعال است. تصاویر نهایی انتشار در پوشهٔ شواهد قرار می‌گیرند.

## حدود نتیجه

پس از انتشار، مشکل دریافت از خود نشانی Sitemap در تست زندهٔ گوگل تأیید نشد: Crawl allowed=Yes و Page fetch=Successful بود. بااین‌حال گزارش Sitemaps همچنان Couldn't fetch دارد؛ این تفاوت صریحاً حفظ شده و علتِ قطعیِ سمت گوگل حدس زده نشده است. درخواست دستی ایندکس خانه نیز به خطای اتصال reCAPTCHA خورد و پذیرش موفق ادعا نشده است. جزئیات در `SEARCH-CONSOLE-SETUP.md`.

امتیاز آزمایشگاهی Lighthouse، سرعت اینترنت واقعی ایران، INP کاربران واقعی، دستگاه فیزیکی، TalkBack یا رتبهٔ جست‌وجو را ثابت نمی‌کند. INP دادهٔ میدانی لازم دارد؛ TBT فقط شاخص آزمایشگاهی کمکی است. دسترس‌پذیری کامل WCAG ادعا نشده است. جست‌وجوی نمونه برای درک قصد استفاده شد؛ حجم، رتبه و رقابت عددی اختراع نشده‌اند. نتیجهٔ ایندکس فقط از گزارش آماده یا URL Inspection گوگل قابل اعلام است.
