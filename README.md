# وب‌سایت حاکم ذهن

نسخهٔ مستقل، بدون نیاز به نصب وابستگی یا بیلد. فقط محتوای این پوشه برای انتشار سایت لازم است؛ کد اندروید، کلید امضا و فایل‌های محیطی را منتشر نکنید.

## اجرا

از همین پوشه `python -m http.server 8090 --bind 127.0.0.1` را اجرا و نشانی `http://127.0.0.1:8090` را باز کنید. بازکردن مستقیم `index.html` هم برای محتوای اصلی ممکن است؛ بررسی نهایی با سرور توصیه می‌شود.

## فایل‌های اصلی

- `index.html`: صفحهٔ اصلی، پیام معرفی برنامه و مسیرهای سه‌گانهٔ ورود
- `design-system/theme.css`: رنگ‌ها، تایپوگرافی و توکن‌های طراحی
- `design-system/reference.css`: استایل عمومی و واکنش‌گرا
- `design-system/reference.js`: جست‌وجو، ناوبری و ابزارهای تعاملی
- `guides.html`، `start.html`، `triggers.html`، `features.html`: راهنماها و معرفی امکانات
- `privacy.html`، `release.html`، `404.html`: صفحات پشتیبانی و وضعیت
- `assets/`: فونت‌ها، تصویرها و مجوزهای مربوط
- `config/hakem_cloud_hub.json`: پیکربندی عمومی مربوط به ارتباط اپ؛ تغییر آن باید با نسخهٔ اپ و سیاست حریم خصوصی هماهنگ باشد
- `sitemap.xml`، `robots.txt`: راهنمای خزش دامنهٔ اختصاصی `hakemzehn.ir`
- `scripts/site_check.py`: آزمون‌های پایهٔ محتوای استاتیک در CI
- `docs/SEO-*.md` و `docs/SEARCH-CONSOLE-SETUP.md`: اسناد سئو و پایش

لینک دریافت رسمی: https://myket.ir/app/ir.hakemzehn.app . دریافت و قیمت نمایش‌داده‌شده در وب‌سایت باید با صفحهٔ واقعی مایکت و نسخهٔ منتشرشده منطبق باشند. فایل‌های مخفی، کلید امضا و کد اندروید را در مخزن عمومی وب‌سایت قرار ندهید.

## انتشار در GitHub Pages

مخزن مستقل عمومی `hosiinabaszadeh84/hakem-zehn-website` از قبل روی GitHub Pages با منبع **GitHub Actions** تنظیم شده است. Commit در شاخهٔ `main` گردش‌کار `.github/workflows/pages.yml` را اجرا می‌کند. منبع Pages را به روش دیگری تغییر ندهید. فایل `.nojekyll` و فایل واقعی تأیید گوگل `google511fb0de5f6155d4.html` حفظ شوند. کد اندروید را عمومی نکنید.

با تغییر دامنه، نشانی‌های canonical، Open Graph، robots.txt و sitemap.xml را به نشانی نهایی تغییر دهید. برای پروژهٔ GitHub، بخش نام مخزن را هم در نشانی‌ها وارد کنید؛ پیوندهای نسبی سایت از مسیر مخزن پشتیبانی می‌کنند.

راهنمای رسمی: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## نگهداری لینک دریافت

لینک مایکت هم‌اکنون مستقیم در HTML صفحات تعریف شده است. با تغییر لینک، شمارهٔ نسخه یا وضعیت انتشار، تمام صفحات و متادیتای مربوط را به‌روزرسانی و آزمون کنید. از `site-config.js` قدیمی استفاده نمی‌شود.

## بررسی

برای هر تغییر، ابتدا `python3 scripts/site_check.py` را اجرا کنید. گردش‌کار GitHub Actions نیز پیش از انتشار همین آزمون را اجرا می‌کند. این بررسی جای تست مرورگر واقعی، Lighthouse، اعتبارسنجی محتوای علمی و بازبینی حریم خصوصی را نمی‌گیرد.

## قابلیت انتقال

این سایت به API، CDN یا ابزار بیلد اجرایی وابسته نیست. فایل‌ها را می‌توان روی میزبانی استاتیک سازگار قرار داد؛ در مهاجرت احتمالی همهٔ URLهای Canonical، منابع 404، Sitemap و مالکیت Search Console را یکپارچه کنید. هیچ فایل APK همراه بسته نیست.
